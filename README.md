Tio chi estas la Lens-Studio-pakajho por Snapchat-lenso "[Flipero](https://www.snapchat.com/lens/013d080c76a5411194a3bc223a4d9d9a)". Ghi ebligas al uzanto ludi fliperon per smartfono ene de apo Snapchat.

Por krei Snapchat-lenson saman au similan al Flipero, oni procedu jene:

1. Startigu Lens Studio.
2. Konservu tie la defaultan projekton kun ajna nomo, ekzemple nomo123. (Ghi estas uzata en la sekva priskribo.)
3. Klaku al Asset Library en Lens Studio.
4. Serchu tie lau Github Konnect en Lens Studio.
5. Instalu ghin en Lens Studio.
6. Klaku tie al Github Konnect.
7. Eventuale estas necese antaue instali [Git](https://git-scm.com/download/win) en sia komputilo, por ke `git`-komandoj funkciu.
8. En la Git Terminal de Lens Studio enigu `git clone https://github.com/AndreasKueck/lensstudioflipero.git` kaj klaku al `Run Git Command`.
9. Tio efikas, ke en via en-komputila projekto-dosierujo nomo123 ekestas dosierujo lensstudioflipero, en kiu sin trovas interalie dosiero nome lensstudioflipero.esproj.
10. Ghin malfermu en Lens Studio (per `File > Open Project`), modifu kaj laubezone konservu sub alia nomo.
